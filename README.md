# Odoo Raffle Management

Professional raffle management module for Odoo 19.

## Features

- Interactive raffle board
- Dynamic ticket generation
- Payment validation workflow
- Ticket reservation system
- Automatic winner selection
- Animated raffle gameplay
- Export raffle board as image
- Customer management integration
- Raffle locking system
- Security groups for validation

## Compatible Versions

- Odoo 19 Community
- Odoo 19 Enterprise

## Main Technologies

- Python
- OWL
- JavaScript
- XML
- PostgreSQL
